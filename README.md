# avisame-places

Fills in the names of places (shops, airports, hospitals, parks) for Avísame, from
[Overture Maps](https://overturemaps.org), one area at a time, as the app needs them.

Only areas (about 5 km across) ever reach this job: never a person, a point or a time. The logs say
totals only. The app and its server are not in this repository.

Map data © Overture Maps Foundation and its contributors (CDLA Permissive 2.0, Apache 2.0, ODbL
sources as listed by Overture).
